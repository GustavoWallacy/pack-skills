# Front-end e design

Telas, dashboards e direção visual.

| Skill | Para quê | Onde está | Licença |
|---|---|---|---|
| [`dashboard-bi`](dashboard-bi/) | dashboards React + Recharts com cross-filter, slicers e KPI cards | 📁 aqui | MIT |
| [`apple-hig-designer`](apple-hig-designer/) | UI no padrão Apple HIG (iOS/macOS), com acessibilidade | 📁 aqui | MIT ([licença do autor](apple-hig-designer/LICENSE)) |
| `frontend-design` | direção visual própria para tela nova, sem o visual genérico de IA | 🔗 [anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/frontend-design) | Apache-2.0 |
| `ui-ux-pro-max` | base de estilos, paletas, fontes e padrões de UX por produto e stack | 🔗 [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | MIT |

## Instalar

```bash
npx skills add GustavoWallacy/claude-skills --skill dashboard-bi -a claude-code
npx skills add GustavoWallacy/claude-skills --skill apple-hig-designer -a claude-code
npx skills add anthropics/skills --skill frontend-design -a claude-code
npx skills add nextlevelbuilder/ui-ux-pro-max-skill --skill ui-ux-pro-max -a claude-code
```

Links das skills de terceiros: [`externas.yaml`](externas.yaml).
