# Marketing

Texto de página, preço, SEO e psicologia aplicada. As quatro vêm do mesmo
repositório: [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills)
(MIT), que tem outras dezenas de skills de marketing.

| Skill | Para quê | Onde está |
|---|---|---|
| `copywriting` | texto de página: home, landing, preço, título, chamada para ação | 🔗 [skills/copywriting](https://github.com/coreyhaines31/marketingskills/tree/main/skills/copywriting) |
| `marketing-psychology` | princípios de psicologia e vieses aplicados a marketing | 🔗 [skills/marketing-psychology](https://github.com/coreyhaines31/marketingskills/tree/main/skills/marketing-psychology) |
| `pricing` | estratégia de preço: planos, pacotes, ancoragem, página de preços | 🔗 [skills/pricing](https://github.com/coreyhaines31/marketingskills/tree/main/skills/pricing) |
| `seo-audit` | auditoria de SEO técnico e de conteúdo | 🔗 [skills/seo-audit](https://github.com/coreyhaines31/marketingskills/tree/main/skills/seo-audit) |

## Instalar

```bash
npx skills add coreyhaines31/marketingskills --skill copywriting -a claude-code
npx skills add coreyhaines31/marketingskills --skill marketing-psychology -a claude-code
npx skills add coreyhaines31/marketingskills --skill pricing -a claude-code
npx skills add coreyhaines31/marketingskills --skill seo-audit -a claude-code
```

Várias de uma vez: `--skill copywriting --skill pricing`.

Links: [`externas.yaml`](externas.yaml).
